{series} {prefix} {id} {id3} {vol} {num} {title} {year}（不分大小写）
{prefix} 是 V / SP，{id} 只有数字（两位 01），{id3} 三位（001）， 想写成 V01 就用 {prefix}{id}。
第一段 = 现有文件夹改成的名字，最后一段 = 每一本的文件名；原地改名，不会把书搬到别的文件夹。
