# ComicManager 2.1.1

这一版打磨刮削页的写入手感与侧车数据：单册写完不再跳页，补上键盘操作，让「不写 Number」对手动编辑的册同样生效，并让 `series.json` 带合集。

## Highlights

- **单册写入留在原页**：「仅应用本册」写完只提示一声，不再重扫整表、不再被送回系列页
- **刮削页键盘操作**：`Ctrl+S` 写入当前选中的分册；方向键切换分册，`Tab` 在当前信息框内循环，回车选中
- **「不写 Number」覆盖手填值**：Kavita 系档位开着时，正传手填的话号也不落盘；番外手填的卷号不受影响
- **残留话号可清掉**：磁盘上残留的 `Number` 不再因跳过判定被误判为「元数据未变化」
- **`series.json` 带合集**：Kavita Custom 档写成 `seriesGroup` 数组（受「生成收藏」开关控制，空值不写）

完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/ComicManager/blob/main/CHANGELOG.md)。

## 下载

下载 `ComicManager-2.1.1-setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicManager`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicManager`

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（未安装时需先安装）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 只处理**元数据与文件名**，图片里已经画上去的字无法转简体
- 转换页只写包里能读到的字段（文件名 / OPF）；要联网补全作者、简介、封面，用刮削页
- 自动判断可能判错（同名作品、简繁混写、冷门作品查不到），判错就在刮削表单里手动指定方向
- 三个来源都是公开 API，条目以日韩与港台出版物为主；简体中文网络漫画的命中率仍有限
- 只收 `.cbz`：CBR（RAR）无法写入包内文件
- WebView2 Runtime 缺失时界面无法加载，只能看到下载提示
- 只支持 Windows，没有 Linux / macOS 版本计划
