# ComicManager 2.1.0

这一版围绕 Kavita Custom 库打磨刮削写入：series.json 换成侧车格式、写号规则改按服务器分流，并把两个写入习惯改成更省心的默认值。

## Highlights

- **Kavita Custom 目标档**（刮削页默认）：`series.json` 按侧车格式写 12 类系列字段（排序名 / 译名 / 简介 / 状态 / 年份 / 语言 / 分级 / 出版社 / 类型 / 标签 / 人员 / 外部链接），优先级高于包内 ComicInfo
- **不写 Number**（Kavita 系档位默认开）：正传只写卷、话只写话，两个字段不互相抄；番外卷号占 0、话号按原顺序保留
- **番外卷号占 0**：独立开关，Kavita Custom 档默认开，关掉则番外卷号清空
- **写入习惯调整**：`series.json` 改为必写；「写前备份 .bak」默认关闭；「留档原 XML」总是保留，不再有开关
- **补 id 即更新**：写入后补齐外部 id 时，`series.json` 的链接同步更新

完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/ComicManager/blob/main/CHANGELOG.md)。

## 下载

下载 `ComicManager-2.1.0-setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicManager`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicManager`

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（未安装时需先安装）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 只处理**元数据与文件名**，图片里已经画上去的字无法转简体
- 转换页只写包里能读到的字段（文件名 / OPF）；联网补全用刮削页
- 自动判断可能判错（同名作品、简繁混写、冷门作品查不到），判错就在界面上手动指定方向
- 三个来源以日韩与港台出版物为主，简体中文网络漫画命中率仍有限
- 只收 `.cbz`：CBR（RAR）无法写入包内文件
- 只支持 Windows，没有 Linux / macOS 版本计划
