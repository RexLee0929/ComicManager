# ComicManager 2.0.0

这一版把程序改名为 ComicManager，并加入完整的元数据刮削；原有的格式转换与界面保持原样。

## Highlights

- **改名为 ComicManager**：安装包、安装目录、快捷方式、卸载登记项一并改名；安装器能识别 1.x（ComicConverter），勾选后卸载旧版并把设置与阅读方向缓存带过来
- **元数据刮削**：Bangumi / MangaUpdates / MangaDex 三个来源任选，按系列匹配、缺字段跨源补齐，也可以纯手填
- **写回只动元数据**：只替换包内 `ComicInfo.xml`，图片字节原样保留；可选 `.bak` 整包备份、把覆盖前的 XML 留档在文件里，随时能「元数据回退」
- **系列级产物**：可选写 `series.json`（Komga）与 `cover.jpg`（中文版 / 原版可选，可限宽）
- **模板重命名**：按 `{series}/{id}` 归档，先预览再执行；番外编 `SP01`、正传编 `V01`
- **三页界面**：首页两个入口，格式转换与元数据刮削各自独立，顶部页签随时切换

## 下载

下载 `ComicManager-2.0.0-setup.exe` 运行即可：

- **仅为我安装**（默认）：`%LOCALAPPDATA%\Programs\ComicManager`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\ComicManager`

### 从 1.x 升级

装过 ComicConverter 的话，「附加任务」页会显示旧版版本与位置，默认勾选「卸载旧版并沿用设置与阅读方向缓存」：

- 复制旧 `config.json`（新目录还没有配置时）与 `origin-cache.json`
- 删旧快捷方式、旧卸载登记项、旧安装目录与旧缓存目录
- 旧版正在运行或设置复制失败时保留旧目录，完成页会写清哪一步没做成

完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/ComicConverter/blob/main/CHANGELOG.md)。

## 系统要求

Windows 10 / 11（x64）；.NET Framework 4.8（未安装时需先安装）；WebView2 Runtime（Win11 自带，Win10 未装时程序会提示下载）。

## 已知限制

- 只处理**元数据与文件名**，图片里已经画上去的字无法转简体
- 转换页只写包里能读到的字段（文件名 / OPF）；联网补全用刮削页
- 自动判断可能判错（同名作品、简繁混写、冷门作品查不到），判错就在界面上手动指定方向
- 三个来源以日韩与港台出版物为主，简体中文网络漫画命中率仍有限
- 只收 `.cbz`：CBR（RAR）无法写入包内文件
- 只支持 Windows，没有 Linux / macOS 版本计划
